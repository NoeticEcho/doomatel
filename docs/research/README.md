## Как читать

1. **Начинать с `09-critique.md`.** Он перечисляет противоречия между
   документами и утверждения без подтверждения. Без него отдельный документ
   легко принять за согласованное решение, каковым он не является.
2. Пометки достоверности внутри документов (`VERIFIED`, `INFERRED`,
   `UNVERIFIED`) относятся к моменту исследования — 20 августа 2026 года.
3. Документ `02` собран со второй попытки: первый запуск прервался.
   Перечень коррупциогенных факторов, реализованный в
   `packages/legal/src/expertise/anticorruption.ts`, **совпал** с перечнем
   из исследования: ровно 12 факторов — девять в пункте 3 (подпункты «а»–«и»)
   и три в пункте 4 (подпункты «а»–«в»). Постановление № 96 менялось не менее
   восьми раз, последнее изменение действует с 27.04.2024; сам перечень
   факторов, по имеющимся данным, с 2010 года не менялся — это утверждение
   помечено в исследовании как непроверенное и требует сверки.

## Поправки, внесённые по итогам реализации

Реализация опровергла часть утверждений исследования. Поправки внесены
в сами документы; здесь сводка:

| Что | Было в исследовании | Оказалось |
|---|---|---|
| Ссылка на исключение официальных документов из авторского права | пункт 5 статьи 1259 | **подпункт 1 пункта 6** статьи 1259 |
| Настройки агента в Mastra 1.60 | `defaultGenerateOptions` | `defaultOptions` |
| Сигнатура `execute` инструмента | `({ context, requestContext })` | `(inputData, context)` |
| Перечисление агентов | `getAgents()` | `listAgents()` |
| Требование писать функции доступа на plpgsql | обязательно, иначе встраивание | **не требуется**: `SECURITY DEFINER` сам запрещает встраивание (проверено `EXPLAIN`) |
| Хранилище графа | TypeDB (документ 01) | PostgreSQL (документ 05, принято) |
