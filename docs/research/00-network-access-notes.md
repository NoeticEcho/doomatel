## Следствия для архитектуры

1. **Парсеры СОЗД нельзя верифицировать вживую из этой среды.** Поэтому ingest-слой
   спроектирован как **fixture-driven**: парсеры пишутся против записанных HTML-фикстур,
   покрыты юнит-тестами, а CLI `doomatel-ingest capture` записывает свежие фикстуры
   при запуске **изнутри РФ**. Это даёт воспроизводимую проверку без доступа к сети.
2. **Транспорт вынесен в интерфейс** (`SourceFetcher`): прямой HTTP, HTTP через прокси,
   Jina Reader и Playwright-браузер — взаимозаменяемы и настраиваются через `.env`.
   Это же решает проблему SPA-страниц (СОЗД рендерится клиентски).
3. `duma.gov.ru` используется как источник справочников (созывы, фракции, комитеты,
   депутаты) и запасной источник по законопроектам.
