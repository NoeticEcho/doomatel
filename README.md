# Doomatel

Мультиагентная платформа для законотворческой деятельности депутатов
Государственной Думы: поиск по действующему праву, подготовка законопроектов
и сопроводительных документов, совместная работа, экспертиза, задачи.

> **Состояние: ранняя разработка.** Реализованы предметный слой, источники
> данных, схема с разграничением доступа, поиск, агенты и прикладной сервис.
> Интерфейс не начат. Часть проверок возможна только изнутри контура —
> см. [docs/04-roadmap.md](docs/04-roadmap.md).

## Устройство

```
apps/
  web/       интерфейс (Next.js) — не начат
  api/       прикладной сервис (NestJS): права, данные, журнал действий
  agents/    агенты и рабочие процессы (Mastra)
packages/
  legal/     предметная область: ссылки, структура актов, экспертиза
  ingest/    источники: СОЗД, ИС «Законотворчество», портал правовой информации
  db/        схема, миграции, политики доступа
  retrieval/ лексика, разбиение на фрагменты, гибридный поиск
infra/       локальная инфраструктура
```

## Запуск

### Требования

- Node.js 22 и pnpm 10
- PostgreSQL 16 или новее (либо Supabase CLI)
- Docker для Qdrant, Redis и объектного хранилища
- эндпоинт языковой модели, совместимый с протоколом OpenAI

### Установка

```bash
pnpm install
cp .env.example .env      # заполнить
pnpm infra:up             # Qdrant, Redis, объектное хранилище, почта
pnpm --filter @doomatel/db build
pnpm --filter @doomatel/db migrate
pnpm build
pnpm dev
```

### Без Docker

Для разработки достаточно локального PostgreSQL:

```bash
eval "$(scripts/test-db.sh)"          # поднимает базу и печатает строку подключения
pnpm --filter @doomatel/db test       # проверка политик доступа
```

## Проверка

```bash
pnpm test          # все пакеты
pnpm typecheck
pnpm lint
```

Проверка политик разграничения доступа требует базы данных и выполняется
на настоящем PostgreSQL, а не на заглушках: политики — это код, который
исполняет база, и проверять его иначе бессмысленно.

```bash
eval "$(scripts/test-db.sh)"
pnpm --filter @doomatel/db test
```

## Источники данных

Загрузка выполняется **изнутри контура**: СОЗД недоступен извне России.

```bash
pnpm --filter @doomatel/ingest build

# проверить доступность источников из текущей сети
node packages/ingest/dist/cli.js probe

# снять снимки карточек для разработки парсеров
node packages/ingest/dist/cli.js capture --bill 149922-8 --out packages/ingest/test/fixtures/sozd

# разобрать снимок и посмотреть результат
node packages/ingest/dist/cli.js parse --file <путь>
```

Ключи ИС «Законотворчество» запрашиваются на `http://api.duma.gov.ru/key-request`.
Для работы из бэкенда нужны оба ключа: ключ API и ключ приложения.

## Языковые модели

Поддерживается **только** протокол, совместимый с OpenAI. Это позволяет
подключить собственный инференс либо российский сервис, предоставляющий
совместимый режим.

```env
LLM_BASE_URL=http://127.0.0.1:8000/v1
LLM_PROVIDER_ID=vllm
LLM_MODEL=qwen3-32b-instruct
```

Без настройки сервис агентов не запускается: молчаливое обращение к внешнему
сервису в этом контуре недопустимо.
